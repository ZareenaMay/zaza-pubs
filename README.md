# My Tasks

A very simple to-do list for a tablet. Add tasks, see them in a list, tick them off when done, and edit or delete them.
Give a task an optional due date, and filter the list by All, To do, Done or Overdue.

- Works in the tablet's web browser, no install or account.
- Tasks are saved on the tablet (browser local storage), so they survive a refresh.
- Clearing the browser's site data will erase the tasks.

## Files
- `index.html` – page structure
- `style.css` – tablet-friendly layout, light and dark mode
- `app.js` – load, add, mark done, edit, delete, due dates, filters, render and save tasks
